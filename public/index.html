ℹ️ About AROI Validation

Authenticated Relay Operator IDs (AROIs) enable Tor relay operators to cryptographically prove ownership of their contact information. This validator automatically checks these proofs to verify relay operator authenticity and build trust in the Tor network.

CIISS v2 — RSA-fingerprint proofs

  • dns-rsa: per-relay DNS TXT record at <rsa-fp>.<domain>
  • uri-rsa: shared file at /.well-known/tor-relay/rsa-fingerprint.txt

CIISS v3 — ed25519 family-ID proofs

  • dns-familyid-ed25519: shared TXT at we-run-this-tor-ed25519-family-id.<domain>
  • uri-familyid-ed25519: shared file at /.well-known/tor-relay/ed25519-family-id.txt

v3 introduces "happy-family" keys: one shared ed25519 key proves ownership across an operator's whole relay family, replacing v2's per-relay RSA fingerprint listings.

Learn more about the ContactInfo Information-Sharing Specification (CIISS) and the AROI framework and trust methodology.
